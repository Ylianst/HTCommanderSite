Address Book

Keep your APRS, Winlink and terminal contacts in one shared address book so the right station is always a click away.

← All features

One place for every contact

HTCommander has a built-in address book that ties the rest of the app together. Keep a list of APRS stations you frequently message, or the terminal profiles you connect to, so you can pick a station quickly instead of retyping a callsign each time.

The address book is also where you store per-station settings that other features rely on — such as the shared password used for authenticated APRS messages and a station's preferred APRS route. It's a simple foundation that makes everything else in the application work better, and there's room to grow it further over time.

Available on all platforms: Windows, macOS, Linux, iOS, Android and web.
