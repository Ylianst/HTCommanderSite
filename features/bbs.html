Built-in BBS

Run your own bulletin board — a private Winlink gateway, a multiplayer text adventure and live station statistics — straight from HTCommander.

← All features

A BBS in your pocket

HTCommander has a built-in BBS, a bit like the old modem days. It's only available if you hold a license and have enabled the app to transmit. Activating it is easy: select a channel on the main or top channel and hit Activate in the top-right of the BBS tab.

Protocols it speaks

The BBS supports AX.25 sessions along with RAW AX.25, APRS and compressed packet formats — the same protocols the terminal supports. An incoming packet must be directed at the station, and the BBS replies in the same format it was received. The AX.25 session and APRS formats include relay/ack support; RAW AX.25 does not.

Winlink gateway and a text adventure

Right now the BBS acts as a private Winlink email gateway, and it hosts a text adventure game called The Adventurer. Any unconnected packet sent to the BBS starts the adventure, and each turn is saved against the sender's callsign — so many stations can play at once, each seeing their own game. Transmit quit at any time to restart.

Live statistics

The BBS tab shows real-time statistics on which stations are using the BBS and how many bytes and packets have been sent and received.

Available on all platforms: Windows, macOS, Linux, iOS, Android and web.
