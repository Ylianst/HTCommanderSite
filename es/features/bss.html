Dos protocolos, una app

HTCommander habla tanto APRS como BSS. APRS está bien documentado, pero BSS parece ser un protocolo propietario no documentado usado por las radios Baofeng / BTech. HTCommander incluye un esfuerzo temprano y funcional para decodificarlo, de modo que los mensajes, ubicaciones y solicitudes de radios de fábrica aparezcan junto a todo lo demás.

Cómo funciona el formato de transmisión

BSS es un protocolo binario sencillo codificado por longitud, transportado en una trama AFSK. Siempre comienza con 0x01, lo que facilita distinguirlo de las tramas AX.25. Después viene una serie de elementos de longitud / tipo / datos.

Un paquete típico se ve así:

0107204B4B37565A540121062468656C6C6F072514C72DC7CDF1

Se decodifica byte a byte como:

01                 // BSS protocol indicator
0720 4B4B37565A54  // Len 0x07, Type 0x20 (From), "KK7VZT"
0121               // Len 0x01, Type 0x21 (To), ""
0624 68656C6C6F    // Len 0x06, Type 0x24 (Message), "hello"
0725 xxxxxxxxxxxx  // Len 0x07, Type 0x25 (Location), Lat + Lng

Es un mensaje de texto con una ubicación donde el campo To está en blanco (lo que ocurre ocasionalmente, aunque normalmente está ausente por completo). Hay una excepción en la codificación: si el campo de longitud es 0x85, los dos bytes siguientes son un contador de mensajes. El contador permite a un receptor ignorar un duplicado del mismo mensaje, y se usa normalmente con solicitudes como pedir una ubicación o un timbre.

Tipos de datos conocidos

TypeNameMeaning
0x20CallsignSource of the message, e.g. N0CALL or N0CALL-0
0x21DestinationMessage destination callsign
0x24MessageA UTF-8 encoded message
0x25LocationSender's position (latitude, longitude, altitude, speed, heading)
0x27LocationRequestRequests the location of a given station
0x28CallRequestRings the requested station, like a phone call
0x85Message counterLength marker followed by a 2-byte counter

A un elemento de ubicación (0x25) le siguen la latitud y la longitud y, opcionalmente, altitud, velocidad y rumbo. Una solicitud de timbre (0x28) hace que la radio de destino emita un pitido, un poco como una llamada telefónica entrante.

Disponible en todas las plataformas: Windows, macOS, Linux, iOS, Android y web.
