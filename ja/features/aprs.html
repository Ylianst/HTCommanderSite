APRS メッセージング

APRS メッセージの送受信、リアルタイムのテレメトリの確認、カスタム経路の設定、一般の電話への送信、気象情報の要求、さらにはメッセージの認証まで — すべて 1 つのタブから行えます。

← すべての機能

アプリの中心

APRS タブは HTCommander のメインタブです。他局のメッセージを読んだり、自分のメッセージを送ったり、絶え間ないテレメトリの流れを見たりできます。無線機が正しく設定されていれば、別のチャンネルで音声を聞いている間も含め、APRS チャンネルを常時監視します。そのため、お気に入りのレピーターに合わせている間に APRS のトラフィックが届いても驚かないでください。

APRS メッセージを送信すると、HTCommander はそのパケットが APRS であることを無線機に伝え、正しい周波数で送信されるようにします。これを機能させるには、APRS という名前のチャンネルが必要です。まだない場合は、HTCommander が作成を手伝うダイアログを表示します。

会話だけを見たい場合は、右上のメニューをクリックしてテレメトリメッセージを非表示にできます。すべての APRS パケットはクリック可能で、AX.25 の経路・位置・グリッドロケーター・コメントの完全なデコードを開いたり、座標を送信した局を右クリックしてミニ地図で表示したりできます。

カスタム経路

File → Settings → APRS で、追加の APRS 経路を登録できます。複数の経路を設定すると、APRS タブの右上にドロップダウンが表示され、送信時に使用する経路を選べます。これにより、メッセージが適切なデジピーターを経由して宛先に届きます。

SMS で一般の電話に送信

コールサインを設定し送信を有効にすると、APRS 経由で一般の携帯電話に SMS を送信できます — 携帯の電波がないときに誰かに連絡したい場合に最適です。受信者はまずオプトインする必要があります。次にアクセスします: aprs.wiki、SMS の返信で確認します。

相手がオプトインしたら、APRS タブの右上のメニューを開き、SMS Message… を選択し、電話番号とメッセージを入力します。番号もメッセージも暗号化されず、認証もされずに送信される点にご注意ください。

オンデマンドの気象通報

コールサインを設定し送信を有効にすると、場所と時刻を指定して気象通報を要求することもできます。右上のメニューから Weather Report… を選び、場所を入力して時刻と通報の種類を選びます。これは次のサービスを利用します: WxBot service.

認証済みメッセージ

HTCommander は認証済みの APRS メッセージを送信できます。2 局以上が HTCommander のアドレス帳に入力した共有パスワードを持ちます。その局へメッセージを送ると、6 桁の認証コードが付加されます。受信側が同じパスワードを持っていれば、メッセージを検証して緑で表示します。一致しない場合は薄いオレンジで表示されます。

パスワードが電波に送られることは決してありません — コードを生成するだけで、コードはメッセージ・パスワード・現在時刻から導出されます。コードは 1 分ごとに変わるため、再送（リプレイ）されたメッセージは検証に失敗します。したがって各局の時計を同期させてください。アマチュア無線では暗号化は認められていませんが、認証は認められています — この機能は認証のみを提供します。これに頼る場合は、長く強力なパスワードを使ってください。多数のメッセージを収集した者が、弱いパスワードを総当たりで破ろうとする可能性があるためです。

これを自分のソフトウェアで実装しますか？ 認証仕様は GitHub で公開されています.

すべてのプラットフォームで利用可能：Windows・macOS・Linux・iOS・Android・Web。関連: リアルタイム APRS マップ and the 共有アドレス帳.
