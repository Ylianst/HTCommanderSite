深入了解

近距离了解每项功能

HTCommander 将一整套电台工具集成到一个应用中——信道编程、消息与地图、邮件与文件传输、软件定义调制解调器、音频与语音等等。下面介绍每项功能的作用，并附有技术细节的链接。

为你的电台编程

信道 · 存储 · 共享 · 设置

信道

信道编辑

手动设置每个信道——名称、接收和发射频率、模式、带宽、功率等级以及 CTCSS/DCS 音频——使用一个精确反映电台要求的简洁编辑器。

阅读文档 →
编程

批量信道编程

从文件导入信道列表，然后将条目直接拖放到电台的信道槽位中。重新排列、复制并在几秒钟内将整个存储库推送到你的手持机，而无需在电台上逐一输入。

阅读文档 →
RepeaterBook

RepeaterBook 导入

无需离开应用即可查找附近的中继台。在全球目录中搜索 RepeaterBook.com 按国家、州和城市搜索，然后将结果直接拖入你电台的信道槽位——频率、偏移和 CTCSS/DCS 音频都会为你填好。中继台数据由以下提供： RepeaterBook.com.

访问 RepeaterBook.com →
共享

通过电波共享信道

在聊天中以可点按的消息形式将信道发送给同频率上的任何人。他们只需轻点即可将其加载到自己的电台中——非常适合让整个小组切换到同一个单工或中继信道。

阅读博客 → 信道字符串工具 →
设置

完整的电台设置

在一处即可深入电台配置的每个角落——PTT 释放行为、信标、可编程按键、已配对的蓝牙设备、音频、功率、发射、显示以及一整套高级开关。在屏幕上更改设置并直接保存回手持机。

APRS

APRS 消息与分组详情

接收和发送 APRS 消息、设置自定义路径、通过短信向普通手机发送信息并请求天气报告。点击任意分组即可打开对 AX.25 路径、位置、网格定位和备注的完整解码。

APRS

给朋友发消息

通过 APRS 消息与朋友保持联系——直接在应用中进行来回对话。为每个联系人设置个性化头像，让每个会话都有一张熟悉的面孔，一眼就能分辨谁是谁。

阅读文档 →
APRS

APRS 推送消息

在 Android 和 iOS 上以推送通知形式接收 APRS 消息，即使应用未打开也能保持联系。点按通知即可直接进入会话并随时回复。

地图

实时 APRS 地图

OpenStreetMap 支持让你一眼看到周围的每个 APRS 电台。跟踪位置历史，点按某个图钉查看电台的呼号和最后收听时间，并一键将地图重新居中到你自己的 GPS 位置。

APRS-IS

APRS-IS 互联网网关

将 HTCommander 连接到 APRS-IS 网络，即可查看和交换来自世界各地的 APRS 流量，远超你电台的覆盖范围。在射频与互联网之间转发位置和消息，并在同一张地图上跟踪远方的电台。

阅读文档 →
通讯录

共享通讯录

将你的 APRS、Winlink 和终端联系人保存在一个共享通讯录中。存储每个电台的呼号、名称、类型、APRS 路径和消息认证设置，让正确的信息始终触手可及。

阅读文档 →
呼号

离线呼号查询

无需联网即可查询任何呼号。内置数据库会返回国家、大洲，以及（对于持照电台）操作员姓名、执照等级、状态、位置和有效期等完整信息，每个字段均可一键复制。

邮件、终端与文件传输

Winlink · 分组 · 种子

Winlink

Winlink 邮件

通过全球 Winlink 网络收发真正的电子邮件——包括附件——可经分组无线电或直接经互联网。熟悉的收件箱、发件箱和撰写窗口让它用起来就像任何邮件客户端。

阅读文档 →
终端

分组终端与 BBS

以经典的分组模式连接到其他电台、用户和 BBS 系统。HTCommander 还内置了一个兼作 Winlink 网关的 BBS，使附近的电台可以通过你接入更广阔的网络。

阅读文档 →
Torrent

种子式文件交换

一次性与整个网络共享一个文件。这个基于 1200 波特 FM-AFSK 的多对多种子系统会跟踪每个数据块、实时压缩数据，并让后加入者赶上进度——而不是逐个链路地占用信道。

数据模式与 DSP

软件调制解调器 · 抓包 · SSTV

调制解调器

高性能软件调制解调器

DART 是新一代、完全软件定义的调制解调器，完全在你的计算机上运行。它通过 LDPC 纠错将调制方式从 BPSK 自适应到 16QAM，显示实时星座图和信噪比读数，并且比传统 AFSK 通过 FM 信道传输更多数据。

阅读文档 →
抓包

分组抓包与解码

观察空中的每一个 AX.25 帧，并打开显示编码、LDPC 纠错、原始字节和十六进制的完整解码。内置分析器非常适合排查你的设置或了解分组无线电的真正工作原理。

阅读文档 →
SSTV

SSTV 收发

收发慢扫描电视图像。传入的信号会被自动检测并在聊天中内联解码，而发送就像把图片拖到窗口上一样简单。

音频与语音

Windows · macOS · Linux · Android

音频

蓝牙音频控制

在一处即可精细调节整条音频链路：选择输入和输出设备、设置电台音量和静噪、调整麦克风增益，并实时查看你所发射内容的频谱图——无需额外接线。

阅读文档 →
语音

离线语音转文字

实时将接收到的电台音频转录为文字——非常适合捕捉繁忙的通联网或 NOAA 气象公告。它在你的设备上完全离线运行，绝不将音频写入磁盘，并可自动识别多种语言。键入的消息也可以在空中被朗读出来。

阅读文档 →
Morse

莫尔斯电键

无需直键或拨片即可操作 CW。HTCommander 在空中发送莫尔斯电码，并将接收到的 CW 实时解码为文字，屏幕读数让你可以轻松跟读或按自己的节奏练习。

在 GitHub 上查看 →
EchoLink

EchoLink 连接

通过互联网远远超越射频范围。按呼号或位置浏览和搜索 EchoLink 节点、链路、中继台和会议室，然后将它们添加为信道，直接在同一个通信窗口中与世界各地的电台通话。

定位与收听

GPS · 卫星 · ADS-B · 探空仪 · FM 广播

GPS

GPS 定位

使用电台内置的 GPS，或插入 USB GPS/GLONASS 适配器以实现精确定位。共享你的位置，让电台自动以信标发送，并一键将地图重新居中到你自己身上。

阅读文档 →
卫星

卫星追踪

自信地操作业余无线电卫星。HTCommander 列出头顶上空和即将出现的每颗卫星，以捕获时间、最大仰角和天线方位角预测每次过境，并实时显示方位角、仰角和距离，让你确切知道该往哪里瞄准。随着卫星在天空中移动，上行和下行频率会实时进行多普勒校正。

在 GitHub 上查看 →
ADS-B

实时飞机追踪

从 dump1090 接收机馈入 ADS-B 数据，观看飞机在与你的 APRS 电台相同的地图上移动——一个有趣而有用的叠加层，把你的电台变成实时天空视图。

阅读文档 →
探空仪

探空仪解码

把你的手持机变成高空接收机。HTCommander 直接从空中解码多个气象气球系列的探空仪，显示每个探空仪的遥测数据——位置、高度、速度等——并在实时地图上绘制每个气球的上升和下降轨迹。
