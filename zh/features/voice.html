音频与语音

语音转文字

实时将接收到的无线电音频转录为文字——完全在你的设备上离线运行——外加文字转语音，可将输入的消息在空中朗读出来。

← 所有功能

在你的机器上运行的 Whisper

HTCommander 内置由 OpenAI 的 Whisper 驱动的语音识别。无线电音频经过神经网络语言模型处理后转换为文字，效果令人印象深刻。需要一颗支持 AVX 的强劲 CPU，并且一切都在本地运行——非常适合跟上繁忙的通联网或收听 NOAA 气象公报。

选择合适的模型

在 HTCommander 内即可选择并下载 Whisper 模型。更大的模型效果更好，但需要更多的 CPU 性能。

模型大小备注
Tiny77.7 MB
Tiny.en77.7 MB仅英语
Base148 MB
Base.en148 MB仅英语（推荐）
Small488 MB
Small.en488 MB仅英语
Medium1.53 GB
Medium.en1.53 GB仅英语

如果你只收听英语，纯英语模型最合适；常规模型支持多种语言。你可以在“设置”面板中选择你将要收听的语言来帮助模型，这会提示它专注于该语言。

何时运行，以及语音回复

启用后，语音识别会在电台停止接收信号时运行，或每 20 到 30 秒运行一次。还有使用 Microsoft Speech API 的文字转语音，因此你可以输入一条消息并让它在空中朗读出来。

仅在桌面端可用：Windows、macOS 和 Linux。
