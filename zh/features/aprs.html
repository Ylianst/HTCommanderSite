APRS 消息

发送和接收 APRS 消息、跟踪实时遥测、设置自定义路径、向普通手机发送信息、请求天气报告，甚至对你的消息进行认证——全部在一个选项卡中完成。

← 所有功能

应用的核心

APRS 选项卡是 HTCommander 的主选项卡。用它来阅读其他电台的消息、发送你自己的消息，并观看源源不断的遥测数据流。如果你的电台设置正确，它会持续监控 APRS 信道——即使你正在另一个信道上收听语音——所以当你停在最喜欢的中继台上时看到 APRS 流量到来，不要感到惊讶。

当你发送 APRS 消息时，HTCommander 会告知电台该分组是 APRS，以便在正确的频率上发射。为使其正常工作，必须存在一个名为 APRS 的信道。如果你还没有，HTCommander 会弹出一个对话框帮助你创建。

如果你只想查看对话，请点击右上角的菜单以隐藏遥测消息。每个 APRS 分组都可点击：打开对 AX.25 路径、位置、网格定位和备注的完整解码，或右键点击发送了坐标的电台以在小地图上查看它。

自定义路径

在 File → Settings → APRS 中，你可以添加额外的 APRS 路径。配置多条路径后，APRS 选项卡的右上角会出现一个下拉菜单，让你在发送时选择使用哪条路径。这样你的消息就能命中正确的数字中继，以到达目的地。

通过短信向普通手机发送信息

配置好呼号并启用发射后，你就可以通过 APRS 向普通手机发送 SMS 短信——当你需要联系某人却没有手机信号时非常合适。收件人必须先选择加入：他们访问 aprs.wiki，并通过 SMS 回复进行确认。

在他们选择加入后，打开 APRS 选项卡右上角的菜单，选择 SMS Message…，然后输入电话号码和消息。请注意，号码和消息都以未加密且未认证的方式传输。

按需天气报告

配置好呼号并启用发射后，你还可以为某个地点和时间请求天气报告。从右上角菜单中选择 Weather Report…，输入地点并选择时间和报告类型。这会使用 WxBot service.

经过认证的消息

HTCommander 可以发送经过认证的 APRS 消息。两个或更多电台共享一个在 HTCommander 通讯录中输入的密码。当你给该电台发消息时，会附加一个 6 位认证码。如果接收方拥有相同的密码，它会验证该消息并以绿色显示；不匹配则以浅橙色显示。

密码绝不会通过电波发送——它只用于生成代码，而代码由消息、密码和当前时间派生而来。由于代码每分钟变化一次，重放的消息将无法通过校验，因此请保持各电台的时钟同步。业余无线电不允许加密，但允许认证——此功能仅提供认证。如果你依赖它，请使用足够长且强的密码，因为捕获大量消息的人可能会尝试暴力破解弱密码。

要在你自己的软件中实现它？ 认证规范已发布在 GitHub 上.

适用于所有平台：Windows、macOS、Linux、iOS、Android 和网页端。相关： 实时 APRS 地图 and the 共享通讯录.
