AGWPE 协议

把其他应用桥接到你的电台

HTCommander 支持 AGWPE，这是一种在业余无线电社区中广泛用于将分组无线电应用程序连接到电台的协议。启用 AGWPE 服务器后，其他软件即可通过 HTCommander 和你的手持机收发分组。

开启它

转到 File → Settings，打开 Services 选项卡并启用 AGWPE Server。通常你会保留默认端口 8000。然后将你的分组应用程序指向该端口——它会看到一个 Port1: Handi-Talky Commander 端口。在该端口上发送即会在电台的 VFO1 上发射。
