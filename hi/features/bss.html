BSS प्रोटोकॉल समर्थन

Baofeng / BTech के मालिकाना शॉर्ट-मैसेज बाइनरी प्रोटोकॉल के लिए समर्थन — रिवर्स-इंजीनियर्ड और प्रलेखित, ताकि HTCommander स्टॉक रेडियो से संदेश, स्थान और अनुरोध डिकोड कर सके।

दो प्रोटोकॉल, एक ऐप

HTCommander APRS और BSS दोनों बोलता है। APRS अच्छी तरह प्रलेखित है, लेकिन BSS एक अप्रलेखित मालिकाना प्रोटोकॉल प्रतीत होता है जिसका उपयोग Baofeng / BTech रेडियो करते हैं। HTCommander में इसे डिकोड करने का एक प्रारंभिक, कार्यशील प्रयास शामिल है ताकि स्टॉक रेडियो से संदेश, स्थान और अनुरोध बाकी सब चीज़ों के साथ दिखाई दें।

वायर प्रारूप कैसे काम करता है

BSS एक सरल लंबाई-कोडित बाइनरी प्रोटोकॉल है जो एक AFSK फ़्रेम में ले जाया जाता है। यह हमेशा 0x01 से शुरू होता है, जिससे इसे AX.25 फ़्रेम से अलग करना आसान हो जाता है। उसके बाद लंबाई / प्रकार / डेटा तत्वों की एक श्रृंखला आती है।

एक सामान्य पैकेट ऐसा दिखता है:

0107204B4B37565A540121062468656C6C6F072514C72DC7CDF1

यह बाइट-दर-बाइट इस प्रकार डिकोड होता है:

01                 // BSS protocol indicator
0720 4B4B37565A54  // Len 0x07, Type 0x20 (From), "KK7VZT"
0121               // Len 0x01, Type 0x21 (To), ""
0624 68656C6C6F    // Len 0x06, Type 0x24 (Message), "hello"
0725 xxxxxxxxxxxx  // Len 0x07, Type 0x25 (Location), Lat + Lng

यह एक स्थान वाला टेक्स्ट संदेश है जहाँ To फ़ील्ड खाली है (जो कभी-कभी होता है, हालाँकि आमतौर पर यह पूरी तरह अनुपस्थित रहता है)। कोडिंग में एक अपवाद है: यदि लंबाई फ़ील्ड 0x85 है, तो अगले दो बाइट एक संदेश काउंटर होते हैं। काउंटर एक रिसीवर को उसी संदेश की डुप्लिकेट को अनदेखा करने देता है, और आमतौर पर स्थान या रिंग माँगने जैसे अनुरोधों के साथ उपयोग होता है।

ज्ञात डेटा प्रकार

TypeNameMeaning
0x20CallsignSource of the message, e.g. N0CALL or N0CALL-0
0x21DestinationMessage destination callsign
0x24MessageA UTF-8 encoded message
0x25LocationSender's position (latitude, longitude, altitude, speed, heading)
0x27LocationRequestRequests the location of a given station
0x28CallRequestRings the requested station, like a phone call
0x85Message counterLength marker followed by a 2-byte counter

एक स्थान तत्व (0x25) के बाद अक्षांश और देशांतर, और वैकल्पिक रूप से ऊँचाई, गति और दिशा आते हैं। एक रिंग अनुरोध (0x28) लक्ष्य रेडियो को बीप कराता है, कुछ-कुछ आने वाले फ़ोन कॉल की तरह।
