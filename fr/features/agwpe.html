Relier d'autres applications à votre radio

HTCommander prend en charge l'AGWPE, un protocole largement utilisé dans la communauté radioamateur pour connecter des applications radio packet à une radio. Avec le serveur AGWPE activé, d'autres logiciels peuvent envoyer et recevoir des paquets via HTCommander et votre portatif.

L'activer

Allez dans File → Settings, ouvrez l'onglet Services et activez le AGWPE Server. Vous conserverez généralement le port par défaut 8000. Dirigez ensuite votre application packet vers ce port — elle verra un port Port1: Handi-Talky Commander. Émettre sur ce port transmet sur le VFO1 de la radio.

Essayez-le

Sur cette page, plusieurs applications classiques compatibles AGWPE sont disponibles, notamment :

  • chess10.zip
  • checkers6.zip
  • easyterm49.zip

Disponible uniquement sur ordinateur : Windows, macOS et Linux.
