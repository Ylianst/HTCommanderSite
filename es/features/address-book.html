Agenda

Guarda tus contactos de APRS, Winlink y terminal en una agenda compartida para que la estación adecuada esté siempre a un clic.

← Todas las funciones

Un solo lugar para cada contacto

HTCommander incluye una agenda integrada que conecta el resto de la aplicación. Mantén una lista de las estaciones APRS a las que envías mensajes con frecuencia, o los perfiles de terminal a los que te conectas, para que puedas elegir rápidamente una estación en lugar de volver a escribir un indicativo cada vez.

La agenda es también donde guardas los ajustes por estación en los que se basan otras funciones, como la contraseña compartida que se usa para los mensajes APRS autenticados y la ruta APRS preferida de una estación. Es una base sencilla que hace que todo lo demás en la aplicación funcione mejor, y hay margen para ampliarla con el tiempo.

Disponible en todas las plataformas: Windows, macOS, Linux, iOS, Android y web.
