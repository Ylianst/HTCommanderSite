すべての機能を間近で

HTCommander は、ステーション一式のツールを 1 つのアプリに凝縮しています — チャンネルのプログラミング、メッセージングと地図、メールとファイル転送、ソフトウェア無線モデム、オーディオと音声など。ここでは各機能の内容を、技術的な詳細へのリンクとともに紹介します。

無線機をプログラミング

チャンネル · メモリー · 共有 · 設定

チャンネル

チャンネル編集

各チャンネルを手動で設定 — 名前、受信・送信周波数、モード、帯域幅、出力レベル、CTCSS/DCS トーン — 無線機が求める内容をそのまま反映する、すっきりしたエディターで行えます。

ドキュメントを読む →
プログラミング

チャンネルの一括プログラミング

ファイルからチャンネルリストをインポートし、項目を無線機のチャンネルスロットに直接ドラッグ＆ドロップできます。無線機で 1 つずつ入力する代わりに、メモリーバンク全体を数秒で並べ替え・コピーしてハンディ機に転送できます。

ドキュメントを読む →
RepeaterBook

RepeaterBook のインポート

アプリを離れずに近くのレピーターを見つけましょう。世界規模のディレクトリを検索できます: RepeaterBook.com 国・州・都市で検索し、結果を無線機のチャンネルスロットへ直接ドラッグできます — 周波数、オフセット、CTCSS/DCS トーンが自動入力されます。レピーターのデータの提供元: RepeaterBook.com.

RepeaterBook.com にアクセス →
共有

電波でチャンネルを共有

チャット内で、周波数上の相手にタップできるメッセージとしてチャンネルを送信できます。相手はタップするだけで自分の無線機に読み込めます — グループ全体を同じシンプレックスやレピーターのチャンネルに揃えるのに最適です。

ブログを読む → チャンネル文字列ツール →
設定

無線機の全設定

無線機の設定のあらゆる部分に 1 か所からアクセスできます — PTT リリースの挙動、ビーコン、プログラマブルボタン、ペアリング済み Bluetooth デバイス、オーディオ、出力、送信、ディスプレイ、そして充実した詳細トグル。画面で設定を変更し、そのままハンディ機に保存できます。

メッセージング＆地図

APRS · 地図 · 連絡先

APRS

APRS メッセージング＆パケット詳細

APRS メッセージの送受信、カスタム経路の設定、SMS による一般の電話への送信、気象情報の要求ができます。任意のパケットをクリックすると、AX.25 の経路・位置・グリッドロケーター・コメントの完全なデコードが開きます。

ドキュメントを読む →
APRS

友だちにメッセージ

APRS メッセージで友だちと連絡を取り合い — アプリからそのまま双方向の会話ができます。連絡先ごとに個人アバターを設定すれば、どのスレッドにもなじみの顔があり、ひと目で誰が誰か分かります。

ドキュメントを読む →
APRS

APRS プッシュ通知

APRS メッセージを Android と iOS のプッシュ通知として受け取れるので、アプリを開いていないときでも連絡を保てます。通知をタップすればそのまま会話に移動し、外出先でも返信できます。

マップ

リアルタイム APRS マップ

OpenStreetMap 対応により、周囲のすべての APRS 局をひと目で表示します。位置履歴をたどり、ピンをタップして局のコールサインや最終受信時刻を確認し、ワンクリックで自分の GPS 位置に地図を再センタリングできます。

ドキュメントを読む →
APRS-IS

APRS-IS インターネットゲートウェイ

HTCommander を APRS-IS ネットワークに接続すれば、無線機の到達範囲をはるかに超えて、世界中の APRS トラフィックを閲覧・交換できます。RF とインターネットの間で位置やメッセージをゲートし、遠方の局を同じ地図上で追えます。

ドキュメントを読む →
アドレス帳

共有アドレス帳

APRS・Winlink・ターミナルの連絡先を 1 つの共有アドレス帳にまとめられます。各局のコールサイン、名前、種別、APRS ルート、メッセージ認証設定を保存でき、必要な情報にいつでもワンクリックでアクセスできます。

ドキュメントを読む →
コールサイン

オフラインでのコールサイン検索

インターネット接続なしで任意のコールサインを検索できます。内蔵データベースが国、大陸、そして免許局については運用者名・免許クラス・状態・所在地・有効期限などの詳細を返し、各項目はワンクリックでコピーできます。

メール・ターミナル＆ファイル転送

Winlink · パケット · トレント

Winlink

Winlink メール

世界規模の Winlink ネットワークを通じて、添付ファイルも含めて本物のメールを、パケット無線またはインターネット経由で送受信できます。使い慣れた受信トレイ・送信トレイ・作成画面により、一般のメールクライアントのように使えます。

ドキュメントを読む →
ターミナル

パケットターミナル＆BBS

従来のパケットモードで、他局・ユーザー・BBS システムに接続できます。HTCommander には Winlink ゲートウェイも兼ねる内蔵 BBS もあり、近くの局があなたを通じてより広いネットワークに到達できます。

Torrent

トレント方式のファイル交換

1 つのファイルをネット全体と一度に共有できます。1200 ボー FM-AFSK 上のこの多対多トレントシステムは、すべてのブロックを追跡し、データをその場で圧縮し、遅れて参加した人も追いつけるようにします — チャンネルを 1 リンクずつ占有する代わりに。

データモード＆DSP

ソフトウェアモデム · キャプチャ · SSTV

モデム

高性能ソフトウェアモデム

DART は、コンピューター上で完結して動作する次世代の完全ソフトウェア無線モデムです。LDPC 誤り訂正を用いて BPSK から 16QAM まで変調を適応させ、リアルタイムのコンスタレーションと SNR 表示を示し、従来の AFSK よりはるかに多くのデータを FM チャンネルで伝送します。

ドキュメントを読む →
キャプチャ

パケットキャプチャ＆デコード

電波上のすべての AX.25 フレームを観察し、符号化・LDPC 訂正・生バイト・16 進数を示す完全なデコードを開けます。内蔵アナライザーは、設定のトラブルシューティングや、パケット無線の実際の仕組みを学ぶのに最適です。

ドキュメントを読む →
SSTV

SSTV の送受信

スロースキャンテレビ（SSTV）の画像を送受信できます。受信信号は自動検出され、チャット内でそのままデコードされます。送信は画像をウィンドウにドラッグするだけです。

オーディオ＆音声

Windows · macOS · Linux · Android

オーディオ

Bluetooth オーディオコントロール

オーディオチェーン全体を 1 か所で微調整できます：入出力デバイスの選択、無線機の音量とスケルチの設定、マイクゲインの調整、送信内容のリアルタイムのスペクトログラフ表示 — 追加の配線は不要です。

ドキュメントを読む →
音声

オフラインの音声認識

受信した無線音声をリアルタイムで文字起こしできます — 混み合ったネットや NOAA の気象通報を把握するのに最適です。デバイス上で完全にオフラインで動作し、音声をディスクに書き込むことはなく、複数の言語を自動認識します。入力したメッセージを電波上で読み上げることもできます。

ドキュメントを読む →
Morse

モールス電鍵

縦振れ電鍵やパドルなしで CW を運用できます。HTCommander はモールス信号を電波に送出し、受信した CW をリアルタイムで文字にデコードします。画面表示により、追いかけたり自分のペースで練習したりが簡単です。

EchoLink

EchoLink 接続

インターネット経由で RF の到達範囲をはるかに超えられます。EchoLink のノード・リンク・レピーター・カンファレンスをコールサインや場所で閲覧・検索し、チャンネルとして追加すれば、同じ通信ウィンドウから世界中の局と話せます。

位置＆受信

GPS · 衛星 · ADS-B · ラジオゾンデ · FM 放送

GPS

GPS 測位

無線機の内蔵 GPS を使うか、USB の GPS/GLONASS ドングルを接続して高精度に測位できます。位置を共有すれば無線機が自動でビーコン送出し、ワンクリックで地図を自分の位置に再センタリングできます。

ドキュメントを読む →
衛星

衛星追尾

アマチュア無線衛星を自信を持って運用できます。HTCommander は頭上や間もなく現れる衛星をすべて一覧表示し、捕捉時刻・最大仰角・アンテナ方位とともに各パスを予測し、方位・仰角・距離をリアルタイム表示するので、どこに向ければよいか正確に分かります。アップリンク・ダウンリンク周波数は、衛星が空を移動するにつれてリアルタイムにドップラー補正されます。

GitHub で見る →
ADS-B

航空機のリアルタイム追尾

dump1090 受信機から ADS-B データを取り込み、APRS 局と同じ地図上を航空機が移動する様子を見られます — あなたのステーションをリアルタイムの空のビューに変える、楽しく有益なオーバーレイです。

ドキュメントを読む →
ラジオゾンデ

ラジオゾンデのデコード

ハンディ機を高層気象の受信機に変えます。HTCommander は複数系統の気象観測気球のラジオゾンデを電波から直接デコードし、各ゾンデのテレメトリ（位置・高度・速度など）を表示し、各気球の上昇と下降をリアルタイム地図に描画します。

ブログを読む →

FM 放送受信機

アプリから直接、無線機を商業 FM 放送局に合わせられます。お気に入りをプリセットとして保存し、ハンディ機に一切触れずに切り替えられます。

Android Auto

HTCommander の主要な操作を車両の Android Auto 画面に。車向けに設計されたインターフェースで、チャンネルの閲覧、接続中の無線機の選択、受信 APRS メッセージの確認ができます。

マルチプラットフォーム

あらゆるプラットフォームで動作

1 つのアプリを、どこでも。HTCommander は Windows・macOS・Linux・iOS・Android・Web でネイティブに動作し — Bluetooth があればどこでも — 持ち歩くどのデバイスでもあなたのステーションが一緒です。

言語

多言語対応

インターフェースはスペイン語から中国語まで多くの言語に翻訳されているので、世界中のオペレーターが自分の言語で快適に HTCommander を使えます。
