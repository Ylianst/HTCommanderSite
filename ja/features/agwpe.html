AGWPE プロトコル

人気の AGWPE プロトコルを使って、他のアプリケーションのパケット通信を無線機経由でルーティングできます — HTCommander がサーバーとして動作します。

← すべての機能

他のアプリを無線機につなぐ

HTCommander は AGWPE に対応しています。これはパケット無線アプリケーションを無線機に接続するために、アマチュア無線コミュニティで広く使われているプロトコルです。AGWPE サーバーを有効にすると、他のソフトウェアが HTCommander とハンディ機を介してパケットを送受信できます。

有効にする

File → Settings を開き、Services タブを開いて AGWPE Server を有効にします。通常はデフォルトのポート 8000 のままにします。次にパケットアプリケーションをそのポートに向けると、Port1: Handi-Talky Commander というポートが表示されます。そのポートで送信すると、無線機の VFO1 で送信されます。

試してみる

このページ には、AGWPE 対応の定番アプリケーションがいくつかあります。たとえば:

  • chess10.zip
  • checkers6.zip
  • easyterm49.zip

デスクトップのみで利用可能：Windows・macOS・Linux。
