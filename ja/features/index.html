機能ガイド

すべての機能のためのガイド

HTCommander は、フル装備の局に相当するツールを 1 つのアプリに詰め込んでいます。以下の各機能には、詳細・スクリーンショット・技術ドキュメントへのリンクを備えた専用ガイドがあります。

無線機をプログラミング

チャンネル・メモリー・共有

チャンネル

チャンネルのプログラミング

チャンネルの設定・インポート・エクスポート・ドラッグ＆ドロップで理想のメモリー配置を作成 — そのうえで、1 通のメッセージでチャンネルを電波で共有できます。

続きを読む →

メッセージング＆地図

APRS・BSS・地図・連絡先

APRS

APRS メッセージング

APRS メッセージの送受信、経路の設定、SMS による一般の電話への送信、気象情報の要求、認証済みメッセージの送信ができます。

続きを読む → 地図

リアルタイム APRS マップ

すべての APRS 局を OpenStreetMap 上に表示し、エリアをオフライン用にキャッシュし、プライバシーも守ります — 隠れたテレメトリはありません。

続きを読む → BSS

BSS プロトコル対応

リバースエンジニアリングして文書化した、Baofeng / BTech の独自ショートメッセージ・バイナリプロトコルをデコードします。

続きを読む → アドレス帳

アドレス帳

APRS・Winlink・ターミナルの連絡先を 1 つの共有アドレス帳にまとめ、アプリ全体からすばやくアクセスできます。

続きを読む →

メール・ターミナル＆ファイル転送

Winlink・パケット・BBS・トレント

Winlink

Winlink メール

世界規模の Winlink ネットワークで本物のメールを送受信 — 添付ファイル対応 — パケット無線でもインターネットでも。

続きを読む → ターミナル

パケットターミナル

クラシックなパケットモードで他の局・ユーザー・BBS システムに接続 — その間も無線機は APRS を監視し続けます。

続きを読む → BBS

内蔵 BBS

自分だけの掲示板を運用 — プライベートな Winlink ゲートウェイとマルチプレイヤーのテキストアドベンチャー、リアルタイムの局統計付き。

続きを読む → Torrent

トレント方式ファイル交換

ネット全体と一度にファイルを共有 — 1200 ボーの FM-AFSK 上での多対多ファイル転送。

続きを読む →

データモード＆DSP

パケットキャプチャ・SSTV・AGWPE

キャプチャ

パケットキャプチャ

電波上のすべてのフレームを観察し、AX.25 / APRS の完全なデコードを開けます — トラブルシューティングやパケット無線の学習に最適。

続きを読む → SSTV

SSTV

低速走査テレビ（SSTV）の画像を送受信。受信した送信は自動検出されてその場でデコードされ、送信はドラッグ＆ドロップです。

続きを読む → AGWPE

AGWPE Protocol

人気の AGWPE プロトコルを使って、他のパケット無線アプリケーションの通信を無線機経由でルーティングします。

続きを読む →

位置＆オーディオ

GPS・衛星・Android Auto・Bluetooth オーディオ・音声認識

GPS

GPS サポート

対応ファームウェアで無線機内蔵の GPS を読み取り、地図上で自分の位置を確認し、ワンクリックで再センタリングできます。

続きを読む → 衛星

衛星トラッキング

リアルタイムの通過予測、アンテナ照準、ドップラー補正済みのアップリンク・ダウンリンク周波数で、アマチュア無線衛星を追尾します。

続きを読む → 車内で

Android Auto

車両の Android Auto ディスプレイから、チャンネルにアクセスし、接続中の無線機を選び、APRS メッセージを追えます。

続きを読む → オーディオ

Bluetooth オーディオ

コンピューターのスピーカー・マイク・ヘッドセットで送受信 — ライブの可視化と充実したデバイスコントロール付き。

続きを読む → 音声

音声認識（Speech-to-Text）

受信した無線音声をリアルタイムでテキストに変換。Whisper で完全オフライン、さらに電波での読み上げにも対応。

続きを読む →
