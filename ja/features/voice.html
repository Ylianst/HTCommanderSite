音声認識（Speech-to-Text）

受信した無線音声をリアルタイムでテキストに変換 — すべて端末上でオフライン処理 — さらに、入力したメッセージを電波に乗せて読み上げるテキスト読み上げ機能も。

← すべての機能

自分のマシンで動く Whisper

HTCommander には、OpenAI の Whisper を利用した音声認識が組み込まれています。無線音声はニューラルネットワークの言語モデルで処理されてテキストに変換され、その精度は見事です。AVX 対応の高性能 CPU が必要で、すべてローカルで動作します — 混み合ったネットや NOAA の気象通報を聞き取るのに最適です。

適切なモデルを選ぶ

HTCommander 内から Whisper モデルを選択してダウンロードできます。大きいモデルほど結果は良くなりますが、より多くの CPU 性能を必要とします。

モデルサイズ備考
Tiny77.7 MB
Tiny.en77.7 MB英語のみ
Base148 MB
Base.en148 MB英語のみ（推奨）
Small488 MB
Small.en488 MB英語のみ
Medium1.53 GB
Medium.en1.53 GB英語のみ

英語だけを聞く場合は英語専用モデルが最適です。通常のモデルは幅広い言語に対応します。設定パネルで聞き取る予定の言語を選ぶと、そのモデルにその言語へ注力するヒントを与えられます。

動作するタイミングと読み上げ

有効にすると、音声認識は無線機が信号を受信しなくなったとき、または 20～30 秒ごとに実行されます。Microsoft Speech API を使ったテキスト読み上げもあり、メッセージを入力して電波に乗せて読み上げさせることができます。

デスクトップのみで利用可能：Windows・macOS・Linux。
