Feature guides

A guide for every feature

HTCommander packs a full station's worth of tools into one app. Each feature below has its own guide with the details, screenshots and links to the technical documentation.

Program your radio

Channels · memories · sharing

Channels

Channel Programming

Configure, import, export and drag & drop channels to build the perfect memory layout — then share a channel over the air with one message.

Read more →

Messaging & mapping

APRS · BSS · maps · contacts

APRS

APRS Messaging

Send and receive APRS messages, set routes, text ordinary phones over SMS, request weather reports and send authenticated messages.

Read more → Map

Live APRS Map

Plot every APRS station on an OpenStreetMap view, cache areas for offline use, and keep your privacy intact — no hidden telemetry.

Read more → BSS

BSS Protocol Support

Decode the proprietary Baofeng / BTech short-message binary protocol, reverse-engineered and documented.

Read more → Address book

Address Book

Keep your APRS, Winlink and terminal contacts in one shared address book for quick access across the app.

Read more →

Email, terminal & file transfer

Winlink · packet · BBS · torrent

Winlink

Winlink Email

Send and receive real email across the global Winlink network — attachments included — over packet radio or the internet.

Read more → Terminal

Packet Terminal

Connect to other stations, users and BBS systems in classic packet mode — while the radio keeps monitoring APRS.

Read more → BBS

Built-in BBS

Run your own bulletin board — a private Winlink gateway and a multiplayer text adventure, with live station statistics.

Read more → Torrent

Torrent File Exchange

Share a file with an entire net at once — many-to-many file transfer over 1200-baud FM-AFSK.

Read more →

Data modes & DSP

Packet capture · SSTV · AGWPE

Capture

Packet Capture

Watch every frame on the air and open a full AX.25 / APRS decode — perfect for troubleshooting or learning packet radio.

Read more → SSTV

SSTV

Send and receive slow-scan television images. Incoming transmissions auto-detect and decode inline; sending is drag & drop.

Read more → AGWPE

AGWPE Protocol

Route other packet-radio applications' traffic over your radio using the popular AGWPE protocol.

Read more →

Location & audio

GPS · Bluetooth audio · speech-to-text

GPS

GPS Support

Read the radio's built-in GPS on supported firmware, see your position on the map, and re-center with one click.

Read more → Audio

Bluetooth Audio

Transmit and receive through your computer's speakers, mic or headset — with live visualization and full device controls.

Read more → Voice

Speech-to-Text

Transcribe incoming radio audio to text in real time, fully offline with Whisper, plus text-to-speech on the air.
